# earth-Geophysics
 
###**1. 區域地理與地質概況**<br>
地理位置：圖中顯示的範圍為冰島本島及其周邊海域，地理座標涵蓋約西經 10° 至 30°、北緯 65° 附近，位於北大西洋板塊交界處。<br>
構造背景：冰島地處歐亞板塊與北美板塊的分離性板塊邊界（大西洋中洋脊），地表呈現高度發育的火山地形與裂谷構造。<br>
###**2. 地震活動特性分析（USGS M2.0 自 2007 年起）**<br>
資料基準：圖面納入了自 2007 年起、規模大於或等於 2.0 的地震事件。<br>
深度分佈：根據圖例，地震事件的震源深度主要集中於淺層（0 至 70 公里），對應圖中標示的紅色區段。<br>
###**3. A-B 震源剖面圖解析**<br>
剖面設定：地圖上的實線 A-B 表示剖面截取路徑，兩側虛線代表 100 公里的廊道範圍，總計包含 699 個地震事件，垂直誇大率（VE）設定為 24.5 倍。<br>
空間聚集性：<br>
在地形剖面（Topo）下方，震源深度分佈顯示出顯著的空間聚集現象。
地震活動高度集中於距離 A 點約 450 至 500 公里處的特定區段，且深度集中於淺部地殼，反映出該區域頻繁的岩漿活動、斷層錯動與地殼張裂應力。<br>
