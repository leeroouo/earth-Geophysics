# 冰島地質與地震活動分析報告

本篇報告針對冰島地區的地形、構造背景以及地震活動進行分析，資料透過 Python 與 PyGmt 自動化程式碼生成[cite: 1, 2]。

---

## 1. 區域地理與地質概況
* **地理位置**：涵蓋冰島本島及其周邊海域，地理座標約為西經 10° 至 30°、北緯 65° 附近，位於北大西洋板塊交界處[cite: 1]。
* **構造背景**：地處歐亞板塊與北美板塊的分離性板塊邊界（大西洋中洋脊），地表火山與裂谷構造高度發育[cite: 1, 2]。

## 2. 地震活動特性分析
* **資料基準**：納入了自 2007 年起、規模 $M \ge 2.0$ 之地震事件[cite: 1, 2]。
* **深度分佈**：震源深度集中於淺層（0 至 70 公里，對應圖例紅色區段）[cite: 1, 2]。

## 3. A-B 震源剖面圖解析
* **剖面設定**：剖面線長度約 859 公里，廊道範圍 $\pm 100$ 公里，總計包含 699 個地震事件，垂直誇大率（VE）為 24.5 倍[cite: 2]。
* **空間聚集性**：多數地震高度集中於距離 A 點約 450 至 500 公里處的淺部地殼，反映出該區頻繁的板塊張裂、斷層錯動與岩漿活動[cite: 1, 2]。
